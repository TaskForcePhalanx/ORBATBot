Where the place names come from

A terrain arrives with roads, buildings and contours and no labels: the tiles come out of Arma’s own map export as pure topography, and the game draws the names over that afterwards from its config. OCAP’s archives carry no names either, so they have to be fetched from the game once per terrain.

Run this in a mission on that terrain: open the debug console as a logged-in admin, paste it, and press LOCAL EXEC. The names land on your clipboard; paste them into the terrain’s Place names box above, or into the upload form below. An archive that already carries a locations list — the Gruppe Adler format — is read on upload and needs none of this.

Upload a terrain

A zip or 7z of the tile folder — the one holding the numbered folders 0/ 1/ 2/ … and, if it came from OCAP, a map.json. The name and the world size are read from that file when it is there, so usually you only have to choose the file.

Arma's marker pictures

{% set icon_count = icon_coverage | sum(attribute='have') %}

Every marker and unit on the maps is drawn with the game's own picture, in its colour, as Arma draws it. The pictures are Bohemia's, so they are not part of this bot: upload them here as a zip of PNGs, laid out as the game keeps them (military/dot_ca.png, nato/b_inf.png, mapcontrol/Church_CA.png) or named after the marker class (loc_Church.png). Only the markers and units this server has a picture for are offered in the editor. The pictures are kept in this bot's database and only this server's members and the holders of a map's share link can load them. Uploading again adds to what is here.
