🏷️ Place names from OCAP

The town names are in the OCAP data, just not in map.json: OCAP builds a terrain from a grad_meh export, which writes them beside the tiles as geojson/locations/…. This reads them from the server this map already points at — no trip into the game.

Names belong to the terrain, so this only has to be done once per terrain and every map on it gains them. If the server carries none, the reply names every address it tried.

Nothing found? Then that terrain was built the older way and carries no location data anywhere — the names exist only in the game. 🎯 Put it into Arma 3 markers in a running mission, no mod

Arma cannot fetch anything from outside without a mod, so the way in is the debug console: paste a script and run it as a logged-in admin (#login, and enableDebugConsole in the mission's description.ext). Both scripts below draw the same plan and are run the same way — LOCAL EXEC, once, on one machine. They differ in one thing: whether anybody can move or delete the markers afterwards.

LOCAL EXEC and not GLOBAL, for both: createMarker is global in Arma, so one machine running it draws the markers for everybody. GLOBAL EXEC would run the script on every machine instead, which is at best wasted and at worst a plan drawn once per player.

Both are built from the saved map, so save first. Where the markers land comes from Arma 3 coordinates in the map settings — set the terrain there before the first export, or everything ends up on Altis. Lines and areas need Arma 2.00 or newer. Running either one again replaces this map's markers rather than adding a second copy.

2 · Markers you can move and delete for planning in game

A marker a script creates is read-only on Arma's map. The engine works out who owns a marker by parsing the name it gives its own — _USER_DEFINED #owner/index/channel — so this version names them that way, and whoever runs it can then drag a symbol or delete it with DEL. Use it when the plan is still being argued about at the map table.

It cuts both ways: the same click that drags a misplaced objective into place deletes it, and nothing asks first. And LOCAL EXEC matters more here than above — the marker's name carries the id of whoever ran the script, so GLOBAL EXEC really would draw one plan per player. The channel below decides which map channel the markers sit in, so a plan meant for one side need not be in Global.
