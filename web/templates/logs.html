Member log

Posts a message when someone joins, leaves, is kicked, banned or unbanned. Pick the channel and tick what you want announced.

{% if not member_events %}

They need Discord's privileged Server Members Intent: tick it under your application → Bot → Privileged Gateway Intents in the Developer Portal, then set MEMBER_EVENTS=1 in the bot's variables and redeploy — in that order, because asking for the intent before it is granted stops the bot from starting at all. Bans and unbans work without it.

Welcome message

Greets a new member directly — separate from the log above, and works whether or not that is switched on. Post it in a channel, send it as a DM, both, or neither.

Skipped quietly for anyone with DMs closed to the bot — nothing is shown for that, the same as a message Discord otherwise refuses.
