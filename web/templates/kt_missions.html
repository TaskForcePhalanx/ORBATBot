Mission names

Every recording the bot has found on the OCAP server. If a mission was not named cleanly, type the name you want in Shown as: the Kill Tracker shows that instead, with the recording’s own date after it. Clear the box to go back to OCAP’s name. Fill in as many as you like, then press Save once — only the names you changed are written, and none are if one of them is not valid. The statistics themselves are not touched, so this survives every re-count.

Tick Don’t count to take a recording out of the Kill Tracker — a test run or a broken mission. It then adds nothing to the statistics, the mission counts or the Active Duty role, and it stays on this page so you can tick it off again.
